The provider configuration and declarative media protocol guide has moved to [docs/en/model-providers.md](./en/model-providers.md).

This compatibility page preserves existing external links. Image, audio, and
video all use Universal Model Adapter V2 protocols with separate target catalogs:

```text
config/universal_model_adapter/protocols/*.json
config/universal_model_adapter/image_targets/catalog.json
config/universal_model_adapter/audio_targets/catalog.json
config/universal_model_adapter/video_targets/catalog.json
```
